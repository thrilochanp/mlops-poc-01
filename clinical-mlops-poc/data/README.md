# Data directory layout

Nothing in here is committed (see `.gitignore`) — it's all regenerated by
the pipeline. Layout, in order of the stages that produce it:

- `raw/<doc_type>/*.png` — synthetic "scanned" clinical document images
  (generate_synthetic_docs.py).
- `raw/ground_truth.jsonl` — the true label + original text used to render
  each image (POC-only convenience, would not exist in a real system).
- `interim/<doc_type>/*.txt` — raw Tesseract OCR output per document
  (ocr_extract.py).
- `interim/ocr_manifest.jsonl` — per-document OCR confidence + text path.
- `interim/normalized.jsonl` — cleaned, field-extracted, PII-redacted text
  ready for modeling (normalize.py).
- `interim/annotations.csv` / `interim/reviews.csv` — human labels and QA
  decisions captured by the Streamlit Annotate / Clinical Review tools.
- `processed/v<N>/{train,val,test}.jsonl` + `manifest.json` — versioned,
  split modeling datasets (dataset_registry.py). Each `manifest.json`
  records a content hash, split sizes, and class balance so a training run
  can always be traced back to exactly the data it saw.
